# אור לנרות — אתר תפילות לחנוכה

## קבצים
- `index.html` — האתר המלא (HTML/CSS/JavaScript ללא תהליך build).
- `manifest.json` — הגדרות PWA.
- `sw.js` — Service Worker בסיסי לשמירת שלד האתר במטמון.

## הפעלה ופרסום
1. העלו את שלושת הקבצים לאותה תיקייה בשרת HTTPS (למשל Netlify, Vercel או אחסון האתר שלכם).
2. פתחו את כתובת האתר. התקנה ו-Service Worker דורשים HTTPS או localhost; פתיחה ישירה כקובץ מקומי לא תפעיל PWA.
3. תוכן פרקי התהילים נטען בזמן אמת מ-API של Sefaria כדי להציג נוסח עברי מנוקד. נדרש חיבור אינטרנט לטעינה ראשונה. אם השירות אינו זמין, מופיע קישור לפרק באתר ספריא.
4. כדי שהאייקון יופיע בכל מכשיר, מומלץ להעלות לשרת גם עותקים מקומיים של הלוגו בגדלים 192x192 ו-512x512, ולעדכן את manifest.json ואת תגי icon בהתאם. הקישור שסופק משמש כרגע ישירות.

## הערת תוכן
הנוסח והמנהגים עשויים להשתנות בין קהילות. האתר מציג את סדר הקריאה כמנהג/הצעה, ולא כפסיקה הלכתית. יש לוודא את הנוסח עם סידור הקהילה או רב מוסמך.
